快速开始

安装包，然后在配置中启用插件。插件只读取项目根目录的 pages.config.ts。 

pnpm add -D @uni-helper/vite-plugin-uni-pages
需要 Node.js 20 或更高版本。
vite.config.ts 
import uniPages from '@uni-helper/vite-plugin-uni-pages'

export default {
  plugins: [uniPages()],
}
